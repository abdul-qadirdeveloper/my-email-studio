# Rules for the leads folder

These rules apply to every file in `leads/`.

- **Practice people only.** Everyone in this folder is made up for practice. They are not real waitlist members.
- **Never add real people.** Do not add real names, real email addresses or any data copied from a real list.
- **Every row needs a consent value.** If a row has no `consent` value, don't use it. Ask before filling it in.
- **Never change the @example.com addresses.** Every email ends in `@example.com`, a domain reserved so it can never receive mail. Keep every address as it is.
